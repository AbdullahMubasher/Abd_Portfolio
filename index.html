A Little About Me

I’m a Computer Science student at Dundrum College Dublin with a longstanding interest in technology and programming. My curiosity began in 4th grade, when I was introduced to coding through Scratch and enjoyed seeing how simple instructions could bring ideas to life.

I’m now developing my skills in Python, databases, and web authoring. I’m interested in how software is built, how data is organised, and how websites can make information accessible and useful. I’m keen to keep learning, strengthen my technical abilities, and apply them to practical projects.

What I'm Learning

I’m building my programming skills with Python, learning how to write code that solves problems and brings ideas to life. I’m also exploring databases and how they help store and organise information so it can be used by websites and other applications.

Alongside that, I’m learning web authoring and how to create websites. I’m getting familiar with the building blocks of a page, how to organise its content, and how to make it useful and easy to explore. There’s a lot to learn, but I enjoy seeing each new skill coming together.

Technical Skills

- Python: Writing simple programs, working with variables and logic, and learning how to solve problems with code. - Databases: Learning how information is stored, organised, and retrieved. - Web authoring: Creating web pages and learning how to structure content with HTML. - Building websites: Practising how to bring text, images, and other page elements together into a working website.
